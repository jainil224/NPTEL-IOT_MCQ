QUESTION 1
What does the ultrasonic sensor measure generally in the AID system?

a. Humidity
b. Distance of the object
c. Soil pH
d. Light intensity  

Correct Answer: b. Distance of the object

Easy Theory / Explanation:
In the Agricultural Intrusion Detection (AID) system, an ultrasonic sensor is used to measure how far an object is from the sensor. It sends ultrasonic sound waves and uses the returning echo to estimate distance.

Why this option is correct:
Option (b) is correct because the assignment says the ultrasonic sensor measures the distance of the detected object.

QUESTION 4
When does sensing coverage guarantee network connectivity?

a. When the transmission range is at least twice the sensing range
b. When the sensing range is at least twice the transmission range
c. When the transmission and sensing ranges are equal
d. When the transmission range is smaller than the sensing range  

Correct Answer: a. When the transmission range is at least twice the sensing range

Easy Theory / Explanation:
The sensing range is the area in which a sensor can detect something. The transmission range is the distance over which it can send data to another node. According to the assignment, sensing coverage guarantees network connectivity when the transmission range is at least twice the sensing range.

Why this option is correct:
Option (a) matches the condition stated in the source PDF.

QUESTION 6

a. Event-driven reporting
b. On-demand reporting
c. Manual reporting
d. Location-based reporting  

Correct Answer: a. Event-driven reporting

Easy Theory / Explanation:
In event-driven reporting, sensor nodes send information when a particular event occurs. In forest-fire monitoring, sensors can report when they detect fire-related conditions, such as an unusual rise in temperature or smoke.

Option (a) is correct because the sensor nodes report when a fire-related event is detected.
QUESTION 7
What does a data mule do?

a. Replaces all sensor nodes
b. Measures only temperature
c. Collects data and carries it to the sink
d. Repairs damaged hardware  

Correct Answer: c. Collects data and carries it to the sink

Easy Theory / Explanation:
A data mule moves through an area, collects stored information from sensor nodes, and carries the information to a sink or collection point. It can be useful when sensor nodes cannot communicate directly with the sink over a network.

Why this option is correct:
Option (c) is correct because collecting and carrying data to the sink is the role described in the assignment.
QUESTION 8
What may happen if a critical stationary sensor node fails?

a. The network may be partitioned
b. All nodes become mobile
c. The sensing range doubles
d. The network repairs itself by movement  

Correct Answer: a. The network may be partitioned

Easy Theory / Explanation:
A network partition occurs when a network breaks into separate groups that cannot communicate with one another. If an important stationary sensor node fails, it may break the communication path connecting different parts of the network.

Why this option is correct:
Option (a) is correct because a critical node failure may divide the network into disconnected parts.

QUESTION 10
Which is an advantage of a stationary wireless sensor network?

a. Easy topology maintenance
b. Automatic movement after node failure
c. Continuously changing topology
d. Unpredictable sensor locations  

Correct Answer: a. Easy topology maintenance

Easy Theory / Explanation:
In a stationary WSN, sensor nodes stay in fixed locations. Because their positions usually do not change, it is easier to know how the nodes are connected and maintain the network topology.

Why this option is correct:
Option (a) is correct because fixed sensor locations make topology maintenance comparatively easier.
QUESTION 11
State whether the following statement is True or False.

Statement: In a UAV network, the network topology may change frequently because the UAVs are mobile.

a. True
b. False  

Correct Answer: a. True

Easy Theory / Explanation:
A UAV is an Unmanned Aerial Vehicle, such as a drone. UAVs move from place to place, so the distances between them and their wireless communication links can change frequently. This causes the network topology to change.

Why this option is correct:
Option (a), True, is correct because UAV mobility can cause frequent changes in network connections.
QUESTION 12
Which is a common issue in UAV networks?

a. Frequent topology changes
b. Fixed relative positions
c. Permanent communication links
d. No possibility of UAV failure  

Correct Answer: a. Frequent topology changes

Easy Theory / Explanation:
UAV networks often have changing connections because drones move relative to one another. A link that works at one moment may become weak or break when the UAVs move apart.

Why this option is correct:
Option (a) is correct because frequent topology changes are a common challenge in mobile UAV networks.
QUESTION 13

a. Only isolated systems
b. No device communication

Option (d), Cross-platform integration, is the capability identified in the assignment.
QUESTION 14
State whether the following statement is True or False.

Statement: In a stationary wireless sensor network, sensor nodes can automatically move to restore connectivity after a node failure.

a. True
b. False  

Correct Answer: b. False

Easy Theory / Explanation:
In a stationary WSN, sensor nodes remain in fixed positions. If one node fails, the other nodes do not automatically move to restore the connection. The failure may require a different network solution or physical maintenance.

Why this option is correct:
Option (b), False, is correct because stationary sensor nodes cannot automatically move to repair connectivity.
QUESTION 15
Which statement best describes M2M communication?

a. Devices can exchange data without direct human control
b. Every data exchange must be performed manually
c. Only one device can communicate at a time
d. Devices cannot communicate through a network  

Correct Answer: a. Devices can exchange data without direct human control

Easy Theory / Explanation:
M2M (Machine-to-Machine) communication allows machines or devices to exchange information automatically through a communication link or network. For example, a sensor can send a reading to a monitoring system without a person manually sending the data.

Why this option is correct:
Option (a) is correct because M2M supports automatic data exchange. Human involvement may still be needed for maintenance or supervision.
