QUESTION 1
According to the ITU Internet Report 2005 discussed in the lecture, the future Internet is expected to become wider and more complex mainly because:

a. Humans will completely stop using the Internet
b. Most Internet traffic may flow between devices and different kinds of things
c. Only desktop computers will remain connected
d. Internet communication will be restricted to email services  

Correct Answer: b. Most Internet traffic may flow between devices and different kinds of things

Easy Theory / Explanation:
The Internet of Things (IoT) connects physical objects such as sensors, machines, vehicles, and home appliances to the Internet. These devices can exchange data automatically. In the future, much Internet communication may happen between devices rather than directly between people.

Why this option is correct:
Option (b) is correct because the report expects communication between devices and different kinds of things to increase.
QUESTION 2
Which of the following are characteristics of IoT systems?

a. Efficient and scalable architecture
b. Unambiguous naming and addressing
c. Presence of sleeping nodes, mobile nodes, and non-IP devices
d. Guaranteed continuous connectivity for every device at all times  

Correct Answer: a, b, c

Easy Theory / Explanation:
IoT systems need an efficient design that can support a large number of devices. Each device needs clear naming or addressing. IoT must also support different types of devices, including mobile devices, devices that sleep to save power, and devices that do not use IP. All devices do not need to stay connected all the time.

Why these options are correct:  
- (a) Efficient and scalable architecture helps IoT support many devices.
- (b) Clear naming and addressing helps identify devices.
- (c) IoT must support different device types and connection conditions.
- (d) is incorrect because some IoT devices connect only when needed.

QUESTION 6
In an IoT network configuration, local addresses may be valid only within a gateway’s domain. The same local address may even appear under another gateway. The main advantage of this strategy is:

a. It increases unnecessary address consumption
b. It helps conserve address space
c. It removes the requirement of a gateway
d. It prevents any device from communicating with the Internet  

Correct Answer: b. It helps conserve address space

Easy Theory / Explanation:
A local address may be used inside one gateway's network and reused in another separate gateway's network. This avoids needing a unique global address for every device in every local network.

Why this option is correct:
Option (b) is correct because reusing local addresses helps save address space.
QUESTION 7
Which of the following functions are associated with IoT gateways in the addressing strategy discussed in the lecture?

a. Providing Internet connectivity
b. Supporting IoT LAN intra-connectivity
c. Obtaining upstream address prefixes using mechanisms such as DHCPv6
d. Delegating addresses to nodes using SLAAC  

Correct Answer: a, b, c, d

Easy Theory / Explanation:
An IoT gateway connects local IoT devices with other networks or the Internet. It can help devices in the local network communicate, obtain network address prefixes, and support address configuration.
- Internet connectivity: lets devices communicate outside the local network.
- IoT LAN intra-connectivity: helps devices communicate within the local IoT network.
- DHCPv6: a protocol that can provide IPv6 configuration information, including address prefixes in supported setups.
- SLAAC: Stateless Address Autoconfiguration, which allows IPv6 devices to configure their own addresses using network advertisements.
Why these options are correct:
All four options are listed as gateway-related functions in the assignment's addressing strategy.
QUESTION 8
Which of the following is true about IPv6 compared to IPv4?

a. IPv6 uses dotted decimal notation
b. IPv6 has a smaller address space than IPv4
c. IPv6 uses hexadecimal notation and supports a much larger address space
d. IPv6 requires broadcast addresses in the same way as IPv4  

Correct Answer: c. IPv6 uses hexadecimal notation and supports a much larger address space

Easy Theory / Explanation:
IPv4 uses 32-bit addresses, usually written in dotted decimal form, such as 192.168.1.1. IPv6 uses 128-bit addresses written in hexadecimal form, such as 2001:db8::1. Because IPv6 has many more possible addresses, it is useful for connecting the large number of devices in IoT.

Why this option is correct:
Option (c) correctly describes IPv6 notation and its larger address space.
QUESTION 9
Which statement correctly represents the design expectation from a good sensor?

a. It should influence the measured property significantly
b. It should respond strongly to unrelated physical properties
c. It should be sensitive to the measured property and should not disturb it
d. It should always produce random output  

Correct Answer: c. It should be sensitive to the measured property and should not disturb it

Easy Theory / Explanation:
A sensor measures a physical quantity such as temperature, pressure, or light. A good sensor should detect the quantity it is designed to measure, avoid reacting unnecessarily to unrelated quantities, and disturb the measured quantity as little as possible.

Why this option is correct:
Option (c) states the expected behaviour of a good sensor.
QUESTION 10
Which of the following statements about sensor resolution are correct?

a. Sensor resolution is the smallest change that the sensor can detect
b. For a digital sensor, resolution is related to the smallest digital output change it can process
c. Sensor resolution and sensor accuracy always refer to exactly the same property
d. Sensor accuracy does not depend only on resolution  

Correct Answer: a, b, d

Easy Theory / Explanation:
Resolution is the smallest change in a measured quantity that a sensor can detect or represent. Accuracy describes how close a measurement is to the true value. These are different properties. A sensor may show very small changes but still give readings that are consistently wrong.

Why these options are correct:  
- (a) describes the meaning of resolution.
- (b) relates digital sensor resolution to the smallest output step.
- (d) is correct because accuracy is affected by factors beyond resolution, such as calibration and bias.
- (c) is incorrect because resolution and accuracy are not the same.

QUESTION 12
A sensor gives different output for the same input value depending on whether that input was reached by increasing or decreasing the measured quantity. This error is called:

a. Quantization error
b. Hysteresis error
c. IPv6 translation error
d. Gateway prefix error  

Correct Answer: b. Hysteresis error

Easy Theory / Explanation:
Hysteresis error occurs when a sensor gives different readings for the same input depending on the direction from which the input was reached. For example, a temperature sensor might show a slightly different output while the temperature is rising than while it is falling.

Why this option is correct:
Option (b) is correct because the output depends on the previous input history.
QUESTION 13

A hydraulic actuator can produce considerable force because liquids are nearly incompressible.

a. False
b. True  

Correct Answer: b. True

Easy Theory / Explanation:
An actuator converts energy into physical movement or force. A hydraulic actuator uses pressurised liquid to produce movement. Since liquids are nearly incompressible, pressure can be transmitted effectively through the liquid, allowing the actuator to produce a large force.

Why this option is correct:
Option (b), True, is correct because hydraulic systems can transmit pressure and generate large forces.
QUESTION 14
Which of the following statements are correct about Shape Memory Polymer actuators?

a. They may respond to stimuli such as light, heat, electrical, magnetic, pH, or moisture changes
b. They can show high strain recovery
c. They may have properties such as low density and biocompatibility
d. They are used only as passive temperature sensors  

Correct Answer: a, b, c

Easy Theory / Explanation:
Shape Memory Polymers (SMPs) are materials that can return toward a previously set shape when exposed to a suitable stimulus. Depending on the material, the stimulus may be heat, light, electricity, moisture, pH, or another trigger. These polymers can offer high shape recovery and low weight; some are also biocompatible.

Why these options are correct:  
- (a) is correct because different SMPs can respond to different stimuli.
- (b) is correct because shape recovery is an important property.
- (c) is correct because low density and biocompatibility may be useful properties.
- (d) is incorrect because SMPs can act as actuators, not only as passive temperature sensors.
