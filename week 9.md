QUESTION 6
In a traditional Wireless Sensor Network (WSN), who is typically responsible for redeployment of the sensor nodes?

a. The Sensor-Cloud Service Provider (SCSP)
b. The end-user of the sensor-cloud
c. The WSN-user
d. A third-party auditor  

Correct Answer: c. The WSN-user

Easy Theory / Explanation:
In a traditional WSN, the WSN-user is responsible for ownership, deployment, redeployment, maintenance, and usage. In the sensor-cloud model described in the assignment, redeployment and maintenance shift to the Sensor-Cloud Service Provider (SCSP), while usage shifts to the end-user.

Why this option is correct:
Option (c), The WSN-user, is responsible for redeployment in a traditional WSN according to the source.

QUESTION 10

QUESTION 11
Why is dynamic and adaptive data caching useful in sensor-cloud, according to the lecture?

a. Because environmental conditions always change extremely fast
b. Because it removes the need for a sensor-owner
c. Because caching eliminates the need for virtualization
d. Because unnecessary sensing during slow environmental change wastes energy  

Correct Answer: d. Because unnecessary sensing during slow environmental change wastes energy

Easy Theory / Explanation:
Environmental conditions sometimes change slowly, so a sensor's readings may remain almost the same for a period. Repeatedly sensing and collecting unchanged data can waste energy. Adaptive caching can help reuse recent data when appropriate and reduce unnecessary sensing.

Why this option is correct:
Option (d) gives the reason stated in the assignment for using dynamic and adaptive caching.

QUESTION 13
Which of the following is listed as a key issue with the traditional cloud model that motivates fog computing?

a. Excess bandwidth availability
b. Volume, latency, and bandwidth limitations of the cloud
c. Too much local processing power at the device level
d. Absence of any IoT devices  

Correct Answer: b. Volume, latency, and bandwidth limitations of the cloud

Easy Theory / Explanation:
The assignment highlights three issues with the traditional cloud model:
- Volume: IoT devices can generate huge amounts of data.
- Latency: Sending data to a distant cloud and waiting for a response may take too long for time-sensitive tasks.
- Bandwidth: Transmitting large amounts of data can use a lot of network capacity.
Fog computing processes some data closer to the devices to help reduce these problems.

Why this option is correct:
Option (b) lists the three cloud limitations discussed in the source.
QUESTION 14
Where is the fog layer positioned in the fog computing architecture?

a. Above the cloud layer
b. Between the cloud and the IoT devices
c. Inside each IoT device only
d. There is no fixed position; it replaces the cloud entirely  

Correct Answer: b. Between the cloud and the IoT devices

Easy Theory / Explanation:
Fog computing adds a layer between IoT devices and the cloud. Fog nodes can process data closer to where it is produced, allowing faster decisions and potentially reducing network traffic and the amount of data sent to the cloud.

Why this option is correct:
Option (b) gives the position of the fog layer as described in the assignment.
QUESTION 15

c. Network connectivity
d. Permanent, unlimited archival storage

Why this option is correct:
Option (d) is correct because permanent, unlimited archival storage is not a listed requirement for fog nodes.
